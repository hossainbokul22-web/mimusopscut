## Planned features

Mimusopscut is in beta.

| Area | Status |
|---|---|
| Projects from the phone's videos and photos, or shared to the app; autosave; rename, duplicate, delete | ✅ |
| The timeline: trim, move, split, delete, duplicate, replace, multi-select, undo and redo; pinch to zoom | ✅ |
| Speed and curves, freeze frame, reverse, volume and fades, crop, mask, chroma key, keyframes | ✅ |
| Overlays and layers with blend modes, opacity, transform and animations | ✅ |
| Filters, adjustments (HSL, curves, colour wheels), video effects, body effects and transitions | ✅ |
| Text: templates, fonts, styles, word art, bubbles, animations and text to speech | ✅ |
| Stickers, labels, shapes and drawing | ✅ |
| Captions made on the phone, typed captions, caption templates and imported subtitles | ✅ |
| Sound effects, voiceover, extract audio, voice effects, noise reduction and isolate voice | ✅ |
| Remove background (a model downloaded once, run on the phone) | ✅ |
| Aspect ratios, backgrounds, cover, AutoCut, collage | ✅ |
| Export at 480p to 4K, 24 to 60 fps, GIF and photo, saved to the gallery and shared | ✅ |
| Translate captions between Bengali, Hindi, English and 11 more languages, on the phone (Google ML Kit, downloads a model once) | ✅ |
| Video templates (Vlog, Reel punch, Cinematic, Memories, Travel story): clip lengths, cuts, colour look, photo moves and an optional title in one tap, from Home or the editor. Reel-style presets (Beat pop, Glide reel, Moody, Hard cuts), and Copy the rhythm of a reel: the cuts of a video you pick are found on the phone and your clips are cut to the same beat (timing only) | 🚧 |
| Storyboard: the main track as a row of scenes with frames and lengths; move a scene earlier or later, or remove it | 🚧 |
| AI Studio: text to image, AI photo edit (remove an object, extend background), image/text to video, extend a clip, video to anime, face swap (with a consent check), story to video. Uses your own Replicate API key; each run is billed to you and the media is sent to Replicate. Story scripts can use any OpenAI-style writing service instead (FreeLLMAPI, Groq, Gemini...), some of them free. Text to image and story pictures also work with no key through a free public service (slow, rate-limited, may change). Also: remove an object from a video (a drawn box, ProPainter), clone a voice from a recording and dub captions with it (Chatterbox multilingual); Bengali is read by the phone's own voice, free, without cloning) | 🚧 |
| Poster maker and Logo maker: a blank page in a chosen size and background, then text templates, stickers and shapes (exports a picture) | ✅ |
| Text to video: type a script, pick pictures, and each line becomes a scene (voiceover, caption, picture, slow zoom or pan) | ✅ |
| Photo motion: a slow zoom or pan over a photo, on one photo or all of them (Image to Video) | ✅ |
| A song shelf (Hindi, Bengali, English) from your own CC0/CC-BY catalogue, and the phone's music (`docs/SONG_CATALOGUE.md`) | 🚧 |
| Downloadable effects and templates | ⬜ |
| Generative AI, cloud storage, accounts | 🚫 Mimusopscut is a local app |

<sub>✅ works today · 🚧 in progress · ⬜ not started · 🚫 not planned</sub>

## Building Instructions
*One Gradle command builds the app: it compiles the Rust engine with [cargo-ndk](https://github.com/bbqsrc/cargo-ndk) and generates the Kotlin bindings. FFmpeg and sherpa-onnx are fetched and built first, once.*

* Clone this repository
* Make sure you have at least 10 GB of free disk space
* In `src`, with `ANDROID_HOME` pointing at your Android SDK:
  ```
  scripts/ffmpeg-mobile.sh aarch64-linux-android
  scripts/sherpa-mobile.sh aarch64-linux-android
  eval "$(scripts/mobile-env.sh aarch64-linux-android)"
  ```
* then enter `src/crates/capcraft-android/android` and run `./gradlew assembleRelease`.

Build time dependencies:

<details>
  <summary>required tools</summary>

  ```
      Linux or macOS (on Windows, WSL)
      rustup (it installs the Rust release rust-toolchain.toml names)
      rustup target add aarch64-linux-android
      cargo install cargo-ndk --version 4.1.2 --locked
      Android SDK (API 37) and NDK 29.0.14206865
      JDK 17 or newer
      cmake, make, clang (libclang-dev), curl
  ```
</details>

*Builds are only tested in WSL Ubuntu on Windows 11.*
